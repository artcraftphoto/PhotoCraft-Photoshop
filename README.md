## Getting Started
1. Download `photocraft-0.5.0-windows-x64-portable.zip`.
2. Extract. Run `photocraft.exe`.
3. Open a PSD or File > New.
4. Layers / masks / type as usual.
5. Notes in `files/notes/`.
